# MOTHWAKE storytelling framework

PLANNED (proposal). Mechanics are extracted from the research, written in MOTHWAKE's own terms.

## 1. Five frame devices (pick ONE per video, and rotate them)
| Device | Shape | Best for | Source of the idea |
|---|---|---|---|
| **Countdown** | Clock-time cards that tick toward the moment | Home invasion, sleep, knocks | tavieenfilm V1 chapters |
| **Rewind** | "Go back to 2:14. Same room." Split screen with an alternative outcome | Twists, A/B stories | tavieenfilm V1 split screen |
| **Rooms** | Numbered rooms or rules, each a mini-verdict, then a "locked" final room | Rules pillar, long-form | tavieenfilm V2 |
| **Suspects** | 3–5 suspects for an uncanny event, then the verdict | Investigations (long-form) | tavieenfilm V3 |
| **Vote** | Ends on a binary choice; the majority picks Part 2 | Interactive pillar | Money Decoded A/B, earlier Shorts research |

## 2. Beat sheet for a Short (20–45 s)
1. **0–1 s:** the wrong image already on screen, plus a giant card (time, number or single word).
2. **1–3 s:** a second-person hook line ("You…"), at most 12 words.
3. **Escalation (2–3 beats):** each beat adds ONE new wrong detail; captions always on.
4. **Device turn:** countdown hits zero / rewind / vote freeze.
5. **Payoff:** a visual reveal that works with no sound.
6. **Loop or CTA:** the last frame leads back into frame 1, or an identity question.

## 3. Writing rules
- Present tense. One idea per sentence. No exposition dumps.
- Facts only in an end card or the description, with a verified source. Never inside the fiction as if it were real.
- Every script must pass the existing similarity gate (`scripts/story/storydb.py`) and an originality review against the competitor notes (no shared premises or lines).

## 4. Long-form "Investigation" (7–11 min) skeleton
Cold open (personal sting) → frame device announced → 3–5 chapters, each ending on a question → reversal → payoff → "the story is fiction / the effect is real" + sources → identity CTA.
