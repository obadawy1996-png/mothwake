## Method and confidence

- Direct page reads were **blocked** in this container (WebFetch DNS failures for elevenlabs.io, remotion.dev, support.google.com and others). Facts come from **WebSearch results restricted to official domains** where possible (labs.google, support.google.com/flow, one.google.com, gemini.google, ai.google.dev, elevenlabs.io, help.elevenlabs.io, remotion.dev, blackmagicdesign.com, opus.pro, help.opus.pro, metricool.com, help.metricool.com, freepik.com, magnific.com, runwayml.com, help.runwayml.com, ffmpeg.org, audacityteam.org).
- Labels: **OFFICIAL** (official domain, via search snippet), **SECONDARY** (third-party), **unverified**.
- Prices are USD list prices as reported; regional prices, taxes and promotions differ. Re-check the pricing page before buying anything. **No paid credits were used and no accounts were created.**
- Connectors exist in this session for ElevenLabs, Magnific and Metricool. They were **not** called (calls could spend credits or touch accounts).

## 2. Tool notes

### 2.1 Google Flow
- **Character consistency workflow ("Ingredients"):** create character sheets / reference images (could be made in Flow with Nano Banana, or imported), add up to 3 image references per clip, prompt the action. Supported on Veo 3.1 Lite and Fast for 8 s clips and Gemini Omni Flash (4 to 10 s); **not** on Veo 3.1 Quality (OFFICIAL, https://support.google.com/labs/answer/16352836).
- **Image-to-video:** Frames to Video with a first frame, or first and last frames (OFFICIAL / Google blog).
- **Do not assume an API.** No public Flow API was found. The Gemini API offers Veo 3.1 (up to 3 reference images, 9:16 native, 1080p/4K; reference-image jobs fixed at 8 s) priced per second: Veo 3.1 Standard USD 0.40/s (720p/1080p), Fast USD 0.10 to 0.12/s, Lite USD 0.05 to 0.08/s; no free tier (OFFICIAL, https://ai.google.dev/gemini-api/docs/pricing ; https://ai.google.dev/gemini-api/docs/veo). Using it would be separate paid usage needing owner approval.
- **Commercial rights:** Google ToS: Google won't claim ownership of generated content. A Flow-specific statement explicitly granting commercial use of video was not found (Google help says "Flow Music includes commercial use rights", which is music-only). Status: **unverified for video**; check Google's Generative AI Additional Terms before monetised use.
- **Watermarks:** SynthID on all outputs (must not be removed). Visible watermark toggle in profile menu (OFFICIAL, https://support.google.com/flow/answer/16353333). A 2025 blog said Ultra Flow videos had no visible watermark; the current toggle supersedes it.
- **Credits:** Flow credits are per *output* (a request producing 2 videos costs 2x). Monthly credits don't roll over. 1080p upscaling is free for Plus/Pro/Ultra (OFFICIAL, 16526234).
- **Prices:** AI Pro USD 19.99/mo; AI Ultra restructured at I/O 2026 into USD 99.99 and USD 199.99 tiers (the old USD 249.99 price is out of date).

### 2.2 ElevenLabs
- Commercial licence starts at **Starter**. Free tier requires attribution and is non-commercial. Any VO intended for publication must come from a paid plan (owner approval needed).
- Voice Design creates a new synthetic voice from a text description: good for original MOTHWAKE narrator voices with no real-person likeness issues.
- Credit pricing is inconsistent across ElevenLabs pages (SFX: 40 credits/s vs 200 credits/generation). Budget conservatively and re-check.

### 2.3 DaVinci Resolve Free: automation conclusion
- **The scripting API is listed as a Studio feature** in the official 21.1 Studio features PDF. External Python/Lua control of the Free edition should be assumed **unavailable**.
- Practical Free-edition pipeline: Python (project venv) writes an **FCPXML or OTIO** timeline referencing rendered shots, VO and SFX; editor imports it via File > Import > Timeline; manual grade, mix and render. FFmpeg handles batch tasks Resolve Free can't be scripted to do.

### 2.4 OpusClip
- For animated horror the useful parts are clipping long episodes into Shorts, captions and reframe. AI Producer is designed for talking-head footage and is not a fit for animation (OpusClip's own description).
- Free plan: watermark, 3-day export window, non-commercial. Do not publish free-plan clips.

### 2.5 Metricool
- Covers all four MOTHWAKE networks on the free plan (1 brand, 20 scheduled posts/mo). API needs Advanced. Scheduling via the connector = publishing, which requires owner approval each time.
